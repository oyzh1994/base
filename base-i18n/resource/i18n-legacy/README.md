# Archived i18n Resources

This directory keeps the historical locale files that are no longer loaded at runtime.

- `base-i18n/`: archived base resources from `base/base-i18n/src/main/resources`.
- Runtime locales are limited to `zh_CN`, `zh_TW`, `en`, `ja_JP`, `de`, `ko_KR`, `fr_FR`, and `it_IT`.
- The files in this directory are retained only for reference and migration. Do not update them together with runtime resources.
